## Shared acceptance checklist (all scenarios)

| Gate | Required |
|------|----------|
| A. Acceptance truth | Every deliverable on frozen Launch Now menu; limits disclosed; rights/timing/clarity/safety/capability checked; unsupported asks refused/narrowed |
| B. Brief coherence | One authoritative brief; offer/audience/tone/CTA/dates/contact/sizes consistent |
| C. Orchestration | Correct production paths; shared facts reused without conflicting copies |
| D. Owner independence | No Tagia design/edit/format/repair labor (approval ≠ production) |
| E. Quality / readiness | Coordinated campaign; commercially usable; correct formats/dimensions; clear packaging |
| F. Journey / mobile | Hire→communicate→track→feedback→approve→delivery observed; mobile defects recorded (not full mobile cert) |
| G. Honest outcome | PASS / PASS WITH EXPLICIT LIMITS / FAIL — not “files exist” |

A scenario may not PASS solely because files were generated. It must pass acceptance truth, orchestration, owner independence, quality, and delivery coherence — or be recorded as **PASS WITH EXPLICIT LIMITS** or **FAIL** with evidence.
