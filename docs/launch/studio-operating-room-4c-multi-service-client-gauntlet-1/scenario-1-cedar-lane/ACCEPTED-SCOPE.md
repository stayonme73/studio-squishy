# Accepted scope — Scenario 1

- Campaign creative (coordinator)
- Social graphics (square PNG)
- Short-form video (vertical MP4)

- Carousel — not on Launch Now menu
- Ad account management / targeting / budgets / ops
- Unsupported sizes outside Studio contracts
- Invented price (none was supplied)
