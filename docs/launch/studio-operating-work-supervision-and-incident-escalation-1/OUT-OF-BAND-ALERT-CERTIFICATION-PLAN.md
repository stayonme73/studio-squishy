# Out-of-band alert certification plan (opening)

Owner Console alert plus a full incident record is required. Before this package can close, **at least one real out-of-band channel** must be live-proven.

**Resend cannot be claimed.** Lifecycle email is parked until domain and branded sender exist.

An alert must identify:

- incident id  
- severity  
- customer/project impact  
- required action (or none)  
- evidence pointer  

It must not say only “something failed.”

Certification later: send a controlled non-production alert, confirm Tagia received it, store the proof on the incident. No fake inbox screenshots.
