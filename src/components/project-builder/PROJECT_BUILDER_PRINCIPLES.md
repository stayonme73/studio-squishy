# Build Your Project — principles

**Locked pattern:** `docs/project-builder-production-pattern-v1-locked.md`

## One sentence

One workspace where the customer browses services, learns in a drawer, adds to a project, and reviews — Squishy guides; the client decides.

## Squishy message types

Each message does **one** of: explain · compare · reassure · suggest.

Never narrate UI controls (*Click*, *Open*, *Add to Project*).

## Reuse rule

Pre-purchase pages after Build Your Project reuse this layout, card system, drawer, summary placement, and Squishy column — not new application layouts.
